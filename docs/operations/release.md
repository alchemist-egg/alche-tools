# 版本与发布

## 当前状态

应用版本 0.1.0。仅配置 Windows NSIS；appId 为 local.alche.tools，尚未确认正式品牌标识、图标、签名和自动更新。Windows/macOS/Linux 是规划目标，不是已验证发行清单。

## 发布流程

1. 确定发布范围，更新 CHANGELOG 与版本；核对 package.json/锁文件版本一致。
2. 记录源码版本标识、锁文件、操作系统/架构、构建工具与执行命令。
3. 运行类型检查和构建；在授权运行验证后执行模块、桌面及安装包验收。
4. 检查数据格式兼容与备份恢复，明确是否可回退。
5. 分平台验证安装、启动、升级、卸载、无开发 Node 环境运行和密钥保护。
6. 实际满足验收后再分发；发布渠道、签名证书和自动更新另行决策。

当前未配置 CI/CD，未自动发布。版本策略建议使用 SemVer：修复 patch、兼容能力 minor、不兼容变更明确迁移与发布说明；0.x 阶段也不能静默破坏用户数据。

## 回退

保留前一版本安装包与匹配的数据备份。应用回退不自动回退数据格式；未知格式不得由旧版改写。记录失败原因和恢复结果，不能把 dist 目录存在作为发布成功证明。
