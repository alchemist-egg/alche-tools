# ADR 0002：HTTP 使用本地加密文件

日期：2026-11-11；状态：已采用（记录当前实现及限制）。

## 背景与决定

首版只需保存有限数量的请求配置。当前使用 safeStorage 加密 JSON 数组、串行保存和临时文件替换，尚未引入 SQLite。

## 取舍与替代方案

文件方案无需数据库驱动和原生 ABI 适配，但每次读取和保存处理完整列表，不适合大量历史或复杂查询。SQLite 是未来候选，早期文档的 SQLite 方向不代表已实现或不可更改的决定。

## 风险与后续

当前无格式版本、迁移、自动备份；系统密钥绑定限制跨设备恢复。串行队列仅解决当前进程内写入顺序，不宣称具备数据库事务、断电持久性或多进程协同能力。先补版本化与迁移设计；规模、查询或实体关系需要时再评估数据库。
