# ADR 0003：三平台规划与手动数据迁移

日期：2026-11-11；状态：已确认规划，尚未全部实施。

## 需求来源

用户明确要求同时规划 Windows、macOS、Linux，并优先通过手动导入导出支持换电脑。

## 决定与影响

设计时考虑三平台路径、生命周期、密钥保护和打包差异；发行声明仅覆盖实际验收的平台。迁移采用独立可移植格式，不将操作系统加密文件视为跨机器备份。暂不以云同步代替手动迁移。

## 未决事项

最低系统版本与架构、平台发布顺序、安装包形式和签名；导出敏感字段策略、口令加密方案、冲突合并行为。上述事项在对应实现开始前确认，不在本次文档变更中猜测落实。
