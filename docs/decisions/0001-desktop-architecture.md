# ADR 0001：模块化桌面架构

日期：2026-11-11；状态：已采用（补录现有实现）。

## 背景与决定

个人工具需要桌面能力和多协议访问。采用 Electron + Vue 3 + TypeScript，Node.js 在主进程模块内执行协议操作，preload 白名单连接界面，不引入额外 HTTP 后端或 Java 进程。

## 取舍

复用 JavaScript 技术栈并减少部署进程；代价是 Electron 体积、内存和安全更新成本。浏览器独立页面难以承载当前桌面需求，额外后端增加生命周期管理成本。

## 重新评估条件

出现明确的协议库缺口、主进程 CPU 瓶颈或无法接受的资源开销时评估适配器、worker 或其他方案，不提前构建跨语言框架。
