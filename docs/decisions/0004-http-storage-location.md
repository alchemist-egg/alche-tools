# ADR 0004 Windows 共享 HTTP 存储位置

状态：已采用，待运行验收。

Windows 开发版和安装版使用同一个 `userData` 目录及单实例锁，共用 HTTP 存储和位置设置。沿用旧安装版的 `%APPDATA%\Alche Tools`，减少对已安装用户的迁移。Chromium 会话继续使用各版本原有目录，保留各自的页面偏好。

目录设置始终写入默认目录，自定义目录可移动或恢复。切换使用密文复制或打开现有库，源库保留，避免未经选择自动合并同 ID 的接口。沿用 [0002](0002-http-storage.md) 的加密方案，迁移和恢复步骤见 [数据生命周期](../operations/data-lifecycle.md)。

位置配置由应用层管理。需要持久化的模块从 `src/main/storage-location.ts` 读取目录，通过同一串行队列协调目录切换和文件操作。模块负责自己的文件格式和切换准备，HTTP 先准备目标库，再由应用层写入设置。
