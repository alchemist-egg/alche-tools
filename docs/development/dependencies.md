# 依赖维护

最低 Node 版本由 engines 声明，开发版本由 .nvmrc 指定，依赖范围由 package.json 声明，实际解析版本由 package-lock.json 锁定。这四者用途不同，升级时一起核对。

建议每月检查一次依赖和安全公告；此频率是维护建议，未创建定时任务。新增依赖前评估维护状态、许可证、安装体积、原生模块及三平台打包影响。

升级流程：记录原因与版本 → 小批量更新 → 类型检查与构建 → 按变更风险安排运行回归 → 记录结果和回退路径。Electron 或原生模块升级必须验证目标平台的二进制与 ABI，不能仅凭 TypeScript 通过发行。

npm audit 的结果必须附日期与锁文件状态；历史告警不代表当前结果。不要自动使用 npm audit fix --force。当前文档整理未联网审计、未升级依赖。
