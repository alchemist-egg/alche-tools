# 测试策略

## 当前状态

npm run build 包含 vue-tsc 和三端构建，已通过。现有 scripts/smoke.cjs 可验证构建产物的 IPC、导航和 Node 隔离，但不验证真正的安装包，也尚未覆盖 HTTP。当前无 HTTP 自动化测试和 CI。

维护偏好：不自动启动应用或联网测试。静态验证不证明网络、存储或安装行为正确；运行验收须明确记录未执行。

## 测试层次

| 层次 | 建议覆盖 | 执行条件 |
| --- | --- | --- |
| 静态 | 类型、构建、文档链接 | 代码或文档修改时 |
| 单元 | 校验、序列化、迁移规则 | 建立测试入口后 |
| 本地集成 | 本地受控 HTTP 服务、取消、超时、压缩和大小限制 | 明确要求运行验证后 |
| 桌面 | 编辑、保存、重启恢复、退出和 IPC 隔离 | 明确要求启动后 |
| 安装包 | 安装、升级、卸载及无 Node 环境 | 每个平台实际发行前 |

不访问生产服务，不使用真实令牌。超时和取消测试应检查连接关闭，不能仅断言提示文字。存储测试使用隔离临时目录，不能覆盖真实 userData。

HTTP 验收场景见模块文档。当前冒烟脚本仍使用固定 30ms 等待，并且测试前不自动构建；后续改为等待明确状态，并避免把输出中的 packaged renderer 误认为安装包验收。
