# 产品定位与范围

## 已确认目标

长期维护的个人桌面开发工具箱，减少 HTTP、Kafka、Redis、编码与加解密工具之间的切换。采用独立 Electron 桌面程序，模块化演进。

2026-11-11 确认：Windows、macOS、Linux 同时纳入产品规划；数据迁移优先实现手动导入导出，支持换电脑。此决定不表示三平台或迁移功能已经可用。

## 当前实现

HTTP 已实现单次请求与本地保存，详见模块文档。编码与加解密已实现 MD5、DES、AES、JWT 解析，待运行验收；Kafka、Redis 为占位页。当前无账号、云端服务、同步、遥测、自动更新或数据库。Windows 关闭窗口退出；macOS 窗口关闭后保留应用进程的生命周期分支已写入代码，但未实机验收。

## 边界

优先单用户、本地数据、中文界面。保持 Electron + Vue + TypeScript + Node.js 模块化单体，不引入额外后端服务。暂不开发插件市场、团队协作和完整集群运维。HTTP 不承诺完整复刻 Postman，按真实使用场景逐项扩展。

## 仍待决策

三平台最低系统版本、CPU 架构、签名与发布渠道；HTTP 后续功能顺序；导出时敏感字段的默认处理和加密口令方案。决定前不写成支持承诺，也不阻塞当前文档和模块维护。
