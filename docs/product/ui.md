# 界面原则

当前中文工作台采用顶部工具模块导航、左侧 56 像素图标栏和底部应用状态栏。点击左侧工作台图标可返回概览。HTTP 工作区包含本地接口列表、请求编辑和响应展示；编码与加解密工作区提供算法参数、输入和结果，离开即清空；Kafka、Redis 明确标记未实现。

左侧外观设置提供浅色、深色和跟随系统。首次使用默认跟随系统，系统主题变化时界面同步更新。所选主题本地保存，适用于概览、工具模块和占位页面。

主题待运行验收：在概览和各模块切换三种模式，确认固定主题独立于系统变化、跟随系统模式即时更新、重启恢复选择，并检查键盘操作和原生表单控件配色。

HTTP 切换模块保留编辑内容；切换请求或新建时询问是否放弃未保存修改；发送期间禁止切换请求，但编辑区仍可修改，正在执行的是发送时快照。响应不保存，也不作为 HTML 执行。

左侧文件夹图标打开应用级存储设置，可从任意模块查看当前目录、选择目录或恢复默认。HTTP 已使用该配置。

长期原则：异步操作显示处理中、失败与取消状态；失败不丢失输入；破坏性操作说明对象；主要功能可通过键盘访问，状态不只依赖颜色。多标签、拖拽分栏和编辑器库尚未承诺。

已知待验收项：窄窗口布局、长响应可读性、屏幕阅读器、未保存退出行为及三平台交互一致性。当前标题和部分文案仍带初始框架措辞，后续界面修改时统一，不代表新增功能未实现。
