# 路线图

无固定工期承诺；功能状态和验证状态分别维护。

| 阶段 | 当前状态 | 完成条件 |
| --- | --- | --- |
| 桌面基础 | 已实现待运行验收 | 启动、导航、隔离、单实例和退出验证 |
| HTTP 首版 | 已实现待运行验收 | 请求、取消、响应、本地保存验收通过 |
| 数据可迁移 | 已确认规划 | 版本化格式、手动导入导出、备份恢复和换电脑验证 |
| 三平台支持 | 已确认规划 | 分别确定系统/架构，构建安装包并实机验收 |
| 其他模块 | 规划 | 根据真实需求完成各模块最小闭环 |
| 长期维护 | 持续进行 | 依赖更新、发布记录、回归和数据兼容维护 |

先补 HTTP 行为验证与数据格式版本，再扩展导入导出。三平台规划应提前评估路径、密钥保护和打包差异，实际发行逐平台记录结果。环境变量、文件上传等 HTTP 增强项尚未确定顺序。
