# HTTP 模块

已实现：GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS、重复查询参数和请求头、JSON/Text/x-www-form-urlencoded 正文、请求取消、100–120000 ms 超时、状态码/响应头/正文展示、JSON 格式化、gzip/deflate/br 响应解压。

支持本地接口新增、更新、删除、集合分组和搜索。完整请求配置通过 Electron safeStorage 加密，保存为 `http-requests.enc`。Windows 开发版与安装版默认共用 `%APPDATA%\Alche Tools`。在「左侧栏 → 存储设置」查看当前目录、选择新目录或恢复默认。响应不持久化；保存通过串行队列和临时文件替换，读失败不覆盖原始数据。迁移与恢复见 [数据生命周期](../operations/data-lifecycle.md)。

限制：请求正文最多 1048576 个 UTF-16 代码单元，响应解压后 5 MiB，最多 8 个并行任务，本地最多 1000 个接口且序列化数据不超过 20 MiB。仅支持 HTTP/HTTPS；TLS 使用默认校验。重定向原样显示 3xx，不自动跟随。认证使用 Authorization 请求头；GET/HEAD 忽略正文。界面切换模块保留编辑状态；切换请求或新建时提示未保存更改。

当前范围不包含完整 Postman 功能：multipart 文件上传、二进制下载、环境变量、Cookie 管理、脚本、代理配置、导入导出与历史记录。响应按 UTF-8 文本显示。

本次验证仅进行类型检查、生产构建和代码检查，按用户要求未启动桌面、未发起网络请求或执行运行时测试。

## 行为验收清单（尚未执行）

- [ ] 同一 Windows 用户分别启动开发版与安装版，读取相同接口及自定义目录设置；同时启动时只保留首个实例。
- [ ] 默认文件缺失时复制旧开发版密文；两处均有文件时默认库优先，旧库可通过选择目录打开。
- [ ] 从概览或任意模块打开左侧「存储设置」。切换到空目录复制原有接口，重启继续使用新目录；切到已有库先确认，取消保留当前目录；恢复默认时验证同样的规则。
- [ ] 升级后读取旧目录设置；首次成功切换后创建应用级设置，旧配置文件保留。
- [ ] 目录不可写、断开、配置损坏或密文无法读取时提示错误；检查设置和原库未被覆盖。切换成功后未保存编辑保留为新草稿。
- [ ] 点击「新建」后打开空白请求，显示新建提示并聚焦 URL；填写后可保存为独立接口。
- [ ] 编辑后点击「新建」或打开已保存接口，应用内弹窗提供继续编辑和放弃修改；按 Escape 保留草稿。
- [ ] 参数启停、重复查询键和重复请求头按输入发送。
- [ ] GET/HEAD 无正文，JSON 无效时提示错误；文本和编码表单按指定类型发送。
- [ ] 2xx/4xx/5xx 均显示真实状态、正文及重复响应头；3xx 不自动跳转。
- [ ] 超时、取消、断网、TLS 错误保留输入并结束任务；取消后服务端连接关闭。
- [ ] gzip/deflate/br 正文正确解压；解压后超过 5 MiB 时终止读取。
- [ ] 保存、更新、集合搜索和删除有效；重启可读取；未保存切换有提示。
- [ ] 存储损坏、加密不可用和写入失败不覆盖原文件。
- [ ] 窗口关闭、renderer 重载/崩溃和退出时清理请求。

当前正文长度校验使用 JavaScript 字符串 length，上限 1048576 个 UTF-16 代码单元，不能等同于 UTF-8 字节数。响应 size 为解压后字节数。当前不保存响应、不自动跟随重定向、不提供独立认证向导。
