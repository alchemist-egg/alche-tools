# HTTP 模块

已实现：GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS、重复查询参数和请求头、JSON/Text/x-www-form-urlencoded 正文、请求取消、100–120000 ms 超时、状态码/响应头/正文展示、JSON 格式化、gzip/deflate/br 响应解压。

支持本地接口新增、更新、删除、集合分组和搜索。完整请求配置通过 Electron safeStorage 加密，保存于 app.getPath('userData') 下的 http-requests.enc。响应不持久化；保存通过串行队列和临时文件替换，读失败不覆盖原始数据。加密不可用时拒绝保存，不回退为明文。

限制：请求正文最多 1048576 个 UTF-16 代码单元，响应解压后 5 MiB，最多 8 个并行任务，本地最多 1000 个接口且序列化数据不超过 20 MiB。仅支持 HTTP/HTTPS；TLS 使用默认校验。重定向原样显示 3xx，不自动跟随。认证使用 Authorization 请求头；GET/HEAD 忽略正文。界面切换模块保留编辑状态；切换请求或新建时提示未保存更改。

当前范围不包含完整 Postman 功能：multipart 文件上传、二进制下载、环境变量、Cookie 管理、脚本、代理配置、导入导出与历史记录。响应按 UTF-8 文本显示。

本次验证仅进行类型检查、生产构建和代码检查，按用户要求未启动桌面、未发起网络请求或执行运行时测试。
