# 模块清单

从顶部工具导航或工作台概览卡片进入模块，点击左侧工作台图标返回概览。模块切换在渲染进程内完成，模块 IPC 见 [IPC 契约](../architecture/ipc.md)。

| 模块 | 当前状态 | 文档/下一步 |
| --- | --- | --- |
| HTTP | 已实现待运行验收 | [功能与验收](http.md) |
| Kafka | 占位，规划 | 明确 Broker、认证、生产/消费场景及停止行为 |
| Redis | 占位，规划 | 明确单机/集群、类型、TTL 和读写边界 |
| 编码与加解密 | 已实现待运行验收 | [MD5、DES、AES、JWT](crypto.md) |

新需求使用 ../templates/requirement.md。复杂模块应分别维护需求、验收与决策，但未形成实际内容前不创建空目录。手动导入导出属于已确认的数据迁移方向，具体格式与敏感信息策略待设计。
