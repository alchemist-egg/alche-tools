# 数据与安全

## 当前实现

窗口开启 contextIsolation 和 sandbox，关闭 nodeIntegration，拒绝新窗口、导航和权限申请。IPC 校验来源；响应文本通过 Vue 文本插值显示，不作为 HTML 执行。

HTTP 请求完整配置通过 safeStorage 加密存入 [当前存储目录](../operations/data-lifecycle.md) 的 `http-requests.enc`。系统加密不可用时拒绝写入，Linux basic_text 后端也拒绝写入。列表读取会将解密配置返回可信 renderer，以便编辑，因此不能把此设计描述为“凭据从不进入界面”。

保存采用串行队列、临时文件和 rename 替换。读取或解析失败不自动重置原文件。响应正文、Cookie 会话、历史记录均不持久化；目前没有业务日志系统或自动备份。

## 输入与资源限制

仅 HTTP/HTTPS，默认 TLS 校验；允许用户明确输入本机或内网地址。URL 内嵌用户名密码被拒绝，认证通过请求头设置。不自动跟随重定向。请求和数据大小限制详见 HTTP 文档。

保存配置可能含令牌、正文和敏感查询参数；不得提交真实请求、解密内容或凭据到版本库。协议错误会显示在界面；当前未建立统一错误脱敏层，提交截图或反馈前须人工检查敏感内容。

## 已确认方向与缺口

跨设备手动迁移已确认，尚未实现。现有文件为加密 JSON 数组，没有 schemaVersion、迁移器或恢复界面。系统加密保护不等同于可跨机器备份。格式变更前遵循 [数据生命周期](../operations/data-lifecycle.md)，不得静默改写旧数据。

未来凭据独立存储、日志脱敏和数据库选型按需求决策，不把规划写为当前能力。

## 编码与加解密数据

输入、密钥、IV 与结果只保留在当前模块内存中，不写入存储和业务日志；离开模块卸载视图，不承诺内存安全擦除。MD5/DES 为兼容工具；AES 首版 CBC/ECB 不提供认证。JWT 内容始终标记未验签，不根据解析字段授予权限。
